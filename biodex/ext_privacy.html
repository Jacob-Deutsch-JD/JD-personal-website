Privacy Policy — iNat Save Taxa (Browser Extension)

Last updated: March 6, 2026

Summary: This extension helps you save iNaturalist taxa to a local dataset and rank them by proximity and seasonality for wildlife photography planning. It is designed to keep your data on your device.

Data the extension handles

  • Location (optional): If you enter a location, click on the map, or use your browser’s location feature, the extension stores latitude/longitude locally to compute proximity rankings.
  • Settings (local): Selected date, ranking scales/sliders, display toggles (such as hiding “found” taxa), and similar preferences are stored locally in your browser.
  • “Found taxa” list (local): A list of taxon IDs you mark as found is stored locally in your browser.
  • Local dataset file (user-controlled): The extension writes a dataset file (for example target-taxa.ndjson) to a folder you choose. This file may include taxon IDs, taxon names, taxon photo URLs, seasonal histograms, and gridded location points derived from iNaturalist observations.

How data is used

All data handled by the extension is used only to provide the extension’s features: saving taxa, refreshing taxa data from iNaturalist, ranking taxa by proximity/seasonality, and displaying results. The extension does not use your data for advertising, profiling, or analytics.

Data sharing

The extension does not send your location, found list, or dataset file to the developer.

The extension connects to third-party services only to retrieve publicly available content needed for its features:

  • iNaturalist API: to retrieve taxon and observation data when you choose “Save / Refresh Taxa”.
  • iNaturalist image hosting: to display taxon photos (using URLs stored in the dataset).
  • OpenStreetMap tile servers: to display the map background tiles.

Data storage and retention

  • Browser-stored data: settings and the found list remain on your device until you clear extension data or uninstall the extension.
  • Dataset file: remains in the folder you selected until you delete it yourself.

Your choices

  • You can change or remove your saved location and settings at any time in the extension’s Options page.
  • You can delete the dataset file from your chosen folder at any time.
  • You can uninstall the extension to remove the extension’s browser storage.

Remote code

The extension does not execute remote code (no externally hosted JavaScript or WebAssembly is run). Network requests are used only to retrieve data/media (e.g., JSON, images, and map tiles).
