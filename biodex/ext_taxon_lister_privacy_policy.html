Taxon Lister Privacy Policy

Effective date: July 13, 2026

Taxon Lister is an independent, unofficial browser extension and is not affiliated with or endorsed by iNaturalist.

Data handled by the extension

Taxon Lister handles only the information needed to provide its listed functionality:

  • The iNaturalist list ID selected by the user.
  • The current iNaturalist username and numeric user ID.
  • The configured list title and owner information.
  • Numeric taxon IDs cached from the configured list.
  • The current iNaturalist taxon page URL and taxon ID when the popup or page-highlighting feature is used.
  • Appearance preferences, cache timestamps, refresh progress, and related extension settings.

Taxon Lister does not read or store the user's iNaturalist password.

How data is used

This information is used only to verify list ownership, determine whether a taxon is already listed, add a user-selected taxon, display list-related links, refresh the local cache, and apply the user's appearance settings.

Storage

Small preferences are stored with the browser's extension sync storage. When browser sync is enabled, the browser provider may synchronize those preferences through the user's browser account. Cached taxon IDs and account/cache metadata are stored locally in the browser's extension storage.

Stored extension data remains until the user changes or clears it, removes the extension, or the browser removes it under its own storage policies. Additions made to an iNaturalist list remain subject to iNaturalist's own data-retention practices.

Network communication and sharing

Taxon Lister communicates directly with www.inaturalist.org to verify the logged-in account and configured list, refresh list membership, and add a taxon when the user clicks the add button. iNaturalist receives the information contained in those requests under its own privacy policy and terms.

Taxon Lister does not send data to the extension developer or any developer-operated server. It does not sell data, use data for advertising, perform analytics or tracking, or share data with third parties except for the browser sync provider and iNaturalist as described above.

Permissions

  • activeTab is used to identify the active iNaturalist taxon page when the user opens the popup.
  • storage is used to save preferences and the local list-membership cache.
  • Access to https://www.inaturalist.org/* is used only for the extension's iNaturalist list and taxon features.

User control

Users can change the configured list and appearance settings from Options, rebuild the local cache with the refresh control, clear extension storage through the browser, or uninstall the extension. Users can remove taxa from their list on iNaturalist and then refresh the local cache.

Changes to this policy

This policy may be updated if Taxon Lister's functionality or data practices change. The effective date will be updated when material changes are made.

Contact

Privacy questions can be sent through the support contact shown on Taxon Lister's Chrome Web Store listing.
